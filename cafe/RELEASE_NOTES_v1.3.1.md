## Coffe Room v1.3.1

Patch release focused on worker-mode layout stability and shift continuity.

### Fixed
- Prevented worker-mode navigation buttons from shrinking when the shift sales summary grows.
- Limited and wrapped the worker shift category summary so it stays inside the header.
- Made cashier cart items scroll while keeping total and checkout buttons fixed at the bottom.
- Wrapped long cart item names to keep checkout rows inside the cart panel.
- Closing the app no longer ends the active worker shift session; shifts now end only through the explicit end-shift button.
