### 1. Mode Selection UI Overhaul (main.py)
**Problem**: Mode selection using Toplevel windows causing z-order and visibility issues

**Solution**:
- Completely rewrote mode selection to use main window directly
- `show_mode_selection()` now clears the main window and displays UI in it
- No more Toplevel windows that could get buried behind other windows
- All UI elements properly displayed in the main window with correct z-order

**Key Changes**:
```python
def show_mode_selection(root):
    """عرض واجهة اختيار الوضع (مالك/عامل)"""
    clear_window(root)  # Clear main window instead of creating Toplevel
    
    root.title("☕ Café POS - اختيار الوضع")
    
    # Display mode selection directly in main window
    header = ctk.CTkFrame(root, height=150, fg_color="#111827")
    header.pack(fill="x", padx=30, pady=30)
    
    # Mode buttons directly in main window
    buttons_frame = ctk.CTkFrame(root, fg_color="transparent")
    buttons_frame.pack(fill="both", expand=True, padx=60, pady=30)
```

### 5. Mode Change Dialog Z-Order Fix (main.py)
**Problem**: Mode change dialog not appearing above current widgets

**Solution**:
- Added `transient(root)` to make dialog properly tied to main window
- Added `focus_force()` and proper z-order attributes
- Ensured dialog appears above all current widgets

**Key Changes**:
```python
def show_change_mode_dialog(root):
    """عرض نافذة تغيير الوضع"""
    dialog = ctk.CTkToplevel(root)
    dialog.title("تغيير الوضع")
    dialog.geometry("500x400")
    dialog.attributes("-topmost", True)
    dialog.focus_force()
    dialog.transient(root)  # Key fix: ties to main window
    dialog.grab_set()
```

### 8. Added clear_window() Helper (main.py)
**Solution**: Helper function to properly clear main window for mode changes

```python
def clear_window(root):
    """مسح محتوى النافذة"""
    for widget in root.winfo_children():
        widget.destroy()
```

This ensures clean transitions between modes without leaving behind old widgets.
