# Fix: Tkinter TclError in Cashier Barcode Scanning
# إصلاح: خطأ TclError في مسح الباركود في الكاشير

## ================================================
# المشكلة
## ================================================

```
_tkinter.TclError: bad window path name ".!ctkframe8.!ctkframe2"
Exception in Tkinter callback
File "C:\Users\Ali\Desktop\cafe\modules\cashier.py", line 163, in on_scan_key
    focused = root.winfo_toplevel().focus_get()
              ~~~~~~~~~~~~~~~~~~~^^
_tkinter.TclError: bad window path name ".!ctkframe8.!ctkframe2"
```

## ================================================
# السبب
## ================================================

عند تغيير نظام الوضع من استخدام `Toplevel` إلى استخدام النافذة الرئيسية مباشرة، تغيرت هيكلة النوافذ:

- **القديم**: `root` كان Toplevel window، فكان `root.winfo_toplevel()` يعمل
- **الجديد**: `root` هو CTkFrame داخل النافذة الرئيسية، فلا يمكن استخدام `winfo_toplevel()` بشكل مباشر

## ================================================
# الحل
## ================================================

### إضافة معالجة الاستثناءات في cashier.py

**قبل**:
```python
def on_scan_key(event):
    focused = root.winfo_toplevel().focus_get()
    if focused == search_entry._entry:
        return
    if not event.char or not event.char.isprintable():
        return
    scan_buffer["chars"] += event.char
    if scan_buffer["timer"] is not None:
        root.after_cancel(scan_buffer["timer"])
    scan_buffer["timer"] = root.after(SCAN_TIMEOUT_MS, flush_scan)

tk_root = root.winfo_toplevel()
tk_root.bind("<Key>", on_scan_key)
```

**بعد**:
```python
def on_scan_key(event):
    try:
        focused = root.winfo_toplevel().focus_get()
        if focused == search_entry._entry:
            return
    except Exception:
        # إذا فشل الحصول على التركيز، استمر في المعالجة
        pass
    
    if not event.char or not event.char.isprintable():
        return
    scan_buffer["chars"] += event.char
    if scan_buffer["timer"] is not None:
        root.after_cancel(scan_buffer["timer"])
    scan_buffer["timer"] = root.after(SCAN_TIMEOUT_MS, flush_scan)

try:
    tk_root = root.winfo_toplevel()
    tk_root.bind("<Key>", on_scan_key)
except Exception:
    # إذا فشل ربط الحدث، تجاهله (المسح الضوئي قد لا يعمل في هذا الوضع)
    print("Warning: Could not bind keyboard events for barcode scanning")
```

## ================================================
# التفاصيل
## ================================================

### 1. داخل دالة on_scan_key:
- لف `root.winfo_toplevel().focus_get()` في try-except
- إذا فشل، استمر في المعالجة بدون التحقق من التركيز
- هذا يمنع الخطأ من إيقاف الوظيفة

### 2. ربط الحدث:
- لف `tk_root = root.winfo_toplevel()` و `tk_root.bind()` في try-except
- إذا فشل، اطبع تحذير ولم تكن مشكلة
- المسح الضوئي بالباركود قد لا يعمل في بعض الحالات، لكن التطبيق لا ينهار
